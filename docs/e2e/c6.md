# E2E: C6 AI pre-sort, NOT RUN

Blocked on purpose. The `llm` module makes Forge treat the build as a major version upgrade (`MAJOR_VERSION_RULE`). Running the build on the dev install needs `forge install --upgrade`, which this run must not run, and deploying a new major to development without upgrading the install would strand later dev deploys. So no deploy, no eligibility check and no live E2E.

What was verified instead: 479 unit tests (`test/presort.test.ts`: minimisation of the request, reply validation, Advanced-only gate, failure paths), typecheck, ESLint, Prettier, build; `forge lint` shows only the major version approval item.
