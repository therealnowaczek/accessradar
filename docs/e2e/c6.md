## Failure found and fixed

First run: the ARTEST project page showed "Review not found" and no review could be started. Cause (not C6): `deleteDraftReview` removed the review but left its `review_assignment` row, so the earlier C8 test cleanup left an orphaned open assignment. Fix (`fix(c6): deleting a review also removes its assignment...`): the delete also removes the assignment, and `findOpenAssignmentForProject` joins `review` so existing orphans are ignored. `npm run check` clean, redeployed dev as 4.1.0, full rerun green. No new test was added for this fix.
